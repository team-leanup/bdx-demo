01 회의에서 요청하신 내용 반영

회원권을 “횟수” → “금액”으로 변경

  • 기존: “10회권”처럼 횟수로 관리
  • 변경: 충전 금액에서 시술할 때마다 차감 (예: 30만 원 충전 → 7만 원 시술 시 23만 원 잔액)
  • 회원권 등록·표시·차감·결제 화면을 전부 금액 기준으로 통일했습니다.

시술 중 추가 항목을 여러 번 자유롭게 추가

  • 시술하면서 제거·연장·래핑·파츠 같은 항목을 개수만큼 반복해서 추가할 수 있게 했습니다.
  • 단가 × 수량이 현재 금액·정산·기록에 바로 반영됩니다.

매장 로고 표시

  • 가입(온보딩)과 설정에서 매장 로고를 올릴 수 있게 했습니다.
  • 올린 로고는 첫 화면, 상단 바, 고객에게 보내는 공유카드에도 함께 표시됩니다.

캘린더 사용성 개선

  • 월별 달력에서 날짜를 누르면 화면이 통째로 바뀌지 않고, 아래 예약 목록만 부드럽게 갱신됩니다.

대시보드 정리

  • ‘오늘 매출’을 대시보드 맨 위로 올려 가장 먼저 보이도록 했습니다.

외국인 고객 배려 — 시술 종류 표기

  • 기본 제공 시술 종류(심플·프렌치·마그넷·아트)는 외국어 화면에서 고객 언어로 자동 번역되어 표시됩니다. (예: ‘아트’ → 영어 Art · 중국어 艺术 · 일본어 アート)
  • 사장님이 직접 추가한 시술 종류는 설정에 입력한 외국어 이름(영어·중국어·일본어)으로 표시되고, 입력하지 않은 언어는 한국어·영문으로 함께 표기됩니다.
  • 시술 예상 시간은 메뉴판에서는 숨기고, 요약 화면에서만 보여주도록 정리했습니다.
  • 사전상담에 “손톱 상태에 따라 시간·비용이 추가될 수 있습니다” 안내 문구를 추가했습니다.

1인샵 표시 개선

  • 디자이너가 1명인 매장은 ‘미지정’ 대신 원장님 이름으로 표시합니다.
  • 발(페디큐어) 옵션은 숨겼습니다.

포트폴리오 / 공유카드

  • 포트폴리오 공유카드 제목을 실제 시술명/카테고리로 표시합니다.
  • 시술 기록 갤러리에 시술 사진뿐 아니라 가입 시 등록한 메뉴 사진까지 함께 보이도록 했습니다.

오너 결정으로 반영한 사항

  • 포인트 아트 추가금을 완전히 제거했습니다. (고객 선택지·가격·정산·설정에서 모두 삭제, 다른 항목 가격에는 영향 없음)
  • ‘시술 항목 관리’ 설정을 없애고 모든 서비스가 항상 보이도록 했습니다. 연장(길게) 옵션도 항상 노출됩니다.
  • 재방문 알림 주기를 설정에서 직접 선택할 수 있게 했습니다. (2주·3주·4주·6주·직접입력 — 기존 4주 고정에서 변경)

02 추가 개선사항

회의에서 요청하신 것 외에, 회의 이후 주신 피드백과 자체적으로 더 다듬은 부분입니다.

더 매끄러운 화면 전환

  • 사전상담 알림을 ‘확인’할 때, ‘시술 시작’을 누를 때 화면이 한 번 깜빡이던 것을 매끄럽게 정리했습니다.

예약 충돌 방지 더 똑똑하게

  • 한 손님이 예약한 시간 범위 전체가 다른 손님에게 정확히 차단되도록 개선했습니다.
  • 예약 종료 시간은 시술 종류별 소요 시간을 기준으로 자동 계산합니다.
  • 직접 손으로 넣은 예약, 이미 완료된 시술 시간대까지 모두 반영됩니다.

화면 표시 다듬기

  • 하단 탭의 ‘포트폴리오’ 글자, 모바일에서 잘리던 글씨들을 모두 보이도록 정리했습니다.
  • 공유카드에서 매 카드마다 똑같이 들어가던 안내 문구를 정리하고, 매장 로고와 실제 시술명을 반영했습니다.
  • 디자이너가 1명인 매장은 프로필이 가운데 정렬되도록 했습니다.

사용 편의 (접근성)

  • 버튼·터치 영역을 손가락으로 누르기 편한 크기로 키우고, 작은 글씨를 읽기 편하게 조정했습니다.
  • 외국어 화면의 번역 문구를 보완했습니다.

속도 개선

  • 무거운 기능은 필요할 때만 불러오도록 바꿔 첫 화면이 더 빠르게 뜨도록 했습니다.

안정성 강화

  • 저장이 정상적으로 되지 않았을 때 사용자가 알 수 있도록 안내를 표시하고, 앱 전체가 멈추지 않도록 안전장치를 보강했습니다.
