## §0. 영업시간 미설정 샵 사전상담 슬롯 0개 (오전, 사용자 Chrome 실측)

DD 테스트 샵 사전상담(`/pre-consult/shop-4ac4e640-...`)에 "지금은 예약 가능한 시간이 없어요"만 떴는데, 사장님 설정 화면엔 영업시간(월~토 10-20시)이 멀쩡히 보이던 문제.

**원인 — 데이터 소스 둘 불일치:** 설정 화면은 `app-store.syncShopSettingsFromShop`의 hydrate fallback(`businessHours.length>0 ? DB값 : store 기본값`)이 DB 빈 배열이면 store 기본값을 화면에만 채워 "거짓 정상"으로 보임. 반면 고객 슬롯은 RPC `get_shop_pre_consult_data`가 DB `business_hours` 컬럼을 직접 읽어 `[]` → `computeAvailableDates`가 전 요일 skip → 슬롯 0. DD는 온보딩 우회 샵이라 영업시간이 한 번도 저장된 적 없음.

**조치(둘 다 라이브 DB, 배포 불필요):** ① DD `business_hours` 백필 ② 마이그레이션 `pre_consult_business_hours_fallback` — RPC가 business_hours 비었으면 기본 영업시간 사용. **빈 배열=미설정**(휴무는 isOpen:false 7엔트리)이라 안전.

상세: 메모리 `business-hours-empty-slot-pitfall.md`.

## §2+. 카톡 미리보기 썸네일 = 샵 로고 OG (피드백 2 확장)

**신규** `src/app/pre-consult/[shopId]/opengraph-image.tsx` + `layout.tsx`에 `generateMetadata` 추가.

- `layout.tsx`는 이미 서버 컴포넌트(`fetchShopPublicData` 호출 중)라 `generateMetadata`로 `title`="{샵이름} 네일 사전상담", `description` 설정 → 카톡 미리보기 텍스트도 샵 맞춤.
- `opengraph-image.tsx`(Next.js 규약 파일 — 자동으로 og:image/twitter:image 주입): `ImageResponse`로 1200×630 가로 카드를 서버 합성. 로고(원형 240px, accent 테두리) + 샵 이름 + 안내 문구 + 하단 BDX 워드마크. 정사각 로고를 그대로 og:image로 쓰면 카톡에서 작게 나오므로 가로 카드 안에 크게 배치.
  - `runtime='nodejs'`, 로고는 `getShopLogoPublicUrl`→`fetch`→data URI 삽입. **PNG/JPG만, SVG·실패·미설정이면 이니셜 폴백**.
  - satori가 Pretendard(variable woff2)를 못 쓰므로 **Google Fonts(Noto Sans KR) subset 동적 로딩**으로 한글 렌더. 폰트 로드 실패해도 카드 구조는 렌더(폴백).
- 빌드 확인: `/pre-consult/[shopId]/opengraph-image` 라우트 생성(ƒ Dynamic).
- **배포 후**: 카톡은 OG를 강하게 캐싱 → 기존 링크는 [카카오 캐시 초기화 도구](https://developers.kakao.com/tool/clear/og)로 1회 갱신 필요. 새 공유 링크는 바로 적용.
