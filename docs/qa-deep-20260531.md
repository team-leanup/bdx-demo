## 2차 QA (Round 2) — 리그레션/이중집계 검증 + 신규 발굴

1차 26건 수정 후 재감사. 멀티에이전트(44에이전트, 7영역 적대적 검증) → 확정 19건(리그레션 8 + 신규 11). **수정 9건 적용**(커밋 8579711 + 교정 4a09d77).

### 1차 수정 검증 결과
- **deposit 이중집계 없음 확인**(코드 추적): 정산 `finalPrice = subtotal − discount − deposit − membership` → `recordRevenue = finalPrice + membership + deposit = subtotal − discount`. 수학적으로 정확.
- 슬롯 후방겹침 오버블록 없음, 예약 status 갱신 정상, designScope 라벨 정상.
