|---|---|---|
| 디자인 느낌 | 심플하고 자연스럽게 / 깔끔한 프렌치 느낌 / 트렌디한 디자인 느낌 / 화려한 아트 느낌 | 내추럴 / 프렌치 / 트렌디 / 화려한 |
